Frequently asked questions

Clear answers about target file limits, visual quality, and format retention.

Can I choose an exact file size limit?

Yes. Set any target size in KB (e.g., 50 KB, 100 KB, or 200 KB). The compression engine recalculates quantization tables to ensure the output stays strictly under your target.

Will image quality or resolution drop?

The engine preserves original pixel dimensions whenever possible. Chroma subsampling and intelligent quantization remove imperceptible high-frequency noise first to retain crisp edges.

Which image formats are supported?

The tool compresses JPEG, JPG, PNG, WEBP, BMP, TIFF, and AVIF files up to 50 MB and returns your image in the same format.

Are uploaded photographs stored or made public?

No. All processing happens in volatile, isolated memory sessions and files are never saved, cataloged, or shared. All session data is discarded immediately.
