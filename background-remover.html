Frequently asked questions

Clear answers about image formats, custom color fills, and privacy.

What file format do I receive after processing?

You receive a 32-bit PNG file. The background is completely transparent unless you provide an optional custom background hex color fill.

How do I fill the background with a custom color?

Type any valid hex code (such as #FFFFFF or #000000) or pick any tone using the color picker tool before clicking remove background.

Which image formats and file sizes are supported?

The studio accepts PNG, JPEG, JPG, WEBP, BMP, TIFF, GIF, and AVIF files up to 50 MB with full native resolution preservation.

Are uploaded photographs stored or made public?

No. Your files are processed securely in isolated memory and never saved, cataloged, or shared. All temporary data is discarded immediately.
