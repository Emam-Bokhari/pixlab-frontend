Common questions

Which scales are available?+

2x, 3x and 4x. The default is 2x.

Will the file size grow?+

Yes. A larger image has more pixels, so the file is bigger. The result panel shows exactly how much.

Which format do I get back?+

The same format as the file you uploaded.
